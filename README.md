# Tab Search for Safari

A Chrome-style tab search popup for Safari. Press **⌘⇧F** and type to filter every open tab across all windows. Then jump to a tab or close it from the keyboard.

## Layout

- `extension/`: the web extension (Manifest V3, plain HTML/CSS/JS). This is the source of truth.
- `Tab Search/`: the Xcode project, generated by `safari-web-extension-converter`. Safari needs a macOS container app to ship an extension. The project references the files in `extension/` directly, so after editing them you only need to rebuild. A **new** file has to be added to the "Tab Search Extension" target's Resources in Xcode, or it won't be bundled.

`content.js` runs on each page and saves the icon the page declares (per site, in `storage.local`). The popup also injects it into open tabs to get their current icon. That's why the extension needs access to all websites.

`background.js` records when each tab was last activated, because Safari doesn't give extensions this. With an empty search, the popup uses it to list tabs most recently used first, like Chrome.

Search follows Chrome's tab search (`chrome/browser/resources/tab_group_shared/search.ts`). Matching is exact substring, ignoring case and accents. Every match scores `(200 − position) / 200 × weight` (title ×2, site ×1). Results are grouped as match at the start of the title or site, then match at the start of a word, then anything else, and sorted by score within each group. One difference from Chrome: each word is matched separately, so word order doesn't matter.

## Build & install

Signing with your Apple Development certificate keeps the extension installed when Safari restarts. Unsigned builds are dropped every time Safari quits.

```sh
xcodebuild -project "Tab Search/Tab Search.xcodeproj" -scheme "Tab Search" \
  -configuration Debug -derivedDataPath build \
  DEVELOPMENT_TEAM=YOUR_TEAM_ID CODE_SIGN_STYLE=Automatic -allowProvisioningUpdates build
open "build/Build/Products/Debug/Tab Search.app"
```

If the build fails with "Embedded binary is not signed with the same certificate", run `rm -rf build` and build again.

The unsigned steps below are only needed if you build without a team (`CODE_SIGN_IDENTITY="-"`).

You can also open the project in Xcode and press Run. To do that, first pick your team under Signing & Capabilities for both targets, or choose "Sign to Run Locally".

Then, in Safari:

1. Settings → Advanced → turn on **Show features for web developers**.
2. Develop menu → **Allow Unsigned Extensions**. Safari resets this each time it quits.
3. Settings → Extensions → enable **Tab Search**, and allow it on all websites so it can read tab titles and URLs.

## Usage

| Key | Action |
| --- | --- |
| ⌘⇧F | Open the popup |
| type | Filter by title or site, ignoring case and accents. Several words narrow the results, in any order |
| ↑ / ↓ | Move the selection |
| Enter | Switch to the tab, even in another window |
| fn⌫ (forward delete) with the caret at the end | Close the selected tab |
| ⌘⌫ with an empty search field | Close the selected tab |
| Esc | Close the popup |

To change the shortcut, go to Safari → Settings → Extensions → Tab Search. If another app already uses ⌘⇧F, the shortcut won't fire, so remap it there.

## Testing the UI in Chrome

The `extension/` folder also loads unpacked in Chrome: go to `chrome://extensions`, turn on Developer mode, and click Load unpacked. That's a quick way to iterate on the popup.

## Distribution

To share the extension, sign it with a Developer ID and notarize it, or submit it through the Mac App Store. Either way you need an Apple Developer account. Set the team in Xcode and use Product → Archive.
